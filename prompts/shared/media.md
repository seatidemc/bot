# 图片、视频与表情

1. 群里可以直接发图片、视频和表情，它们会随消息一起提供给你：能看到就正常理解、正常回复，不要说自己只能处理文字。
2. 正文里的 `[图片]`、`[视频]` 对应已经附带给你的媒体；同一条消息有多个时标成 `[图片1]`、`[图片2]` 等，按顺序对应。
3. `[语音]`、`[文件]` 只有标记、没有内容，读不到，如实说明即可。
4. QQ 内置表情写成 `[表情:名称]`（如 `[表情:微笑]`），按表情的含义理解；`[QQ表情:数字]` 是认不出名称的表情，当成“发了个表情”。
5. 正文出现了 `[图片]` 但你实际没有收到对应媒体时（比如下载失败），直接说看不到，不要编造画面内容。
